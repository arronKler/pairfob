How does it work?

How is it different?

Not a remote desktop,
and not agents in the cloud.

  • NotRemote desktop / VNC / screen share

    Attaches to sessions, not the whole desktop

  • NotAnother terminal in the browser

    Opens the session already running on the computer

  • NotAgents moved into the cloud

    Agents still run on your computer

  • NotA cut-down mobile agent

    What the computer can do is what the phone can do

  • NotAn account login

    Pairing is authorization; the credential stays in this browser

  • NotA VPN / Tailscale

    The computer dials out; you do not open ports at home

Is it secure?

Direct whenever possible:
sessions skip the relay.

By default your phone and computer connect directly (P2P), so session data never passes through pairfob.com. Only when a direct path fails does it go through the relay, and the relay only forwards ciphertext; it can't see the screen or what you type.

The relay also helps the two sides find each other; the messages that set up the direct link are encrypted too. To find a direct path, the browser asks Cloudflare's public-address lookup service once, and that service sees this device's public IP address.

Still have questions?

FAQ

Didn't find it? Read the docs or open a GitHub issue. Report security issues privately.

Do I need to install an app on my phone?

No. Open pairfob.com/pair in the phone's browser. Add it to the Home Screen and it works like an app.

Does locking the screen or closing the lid still work?

A locked screen is fine. A closed lid only works if the machine does not sleep. Pairfob cannot wake a sleeping computer.

Can I install pairfob on Windows?

Not yet. A Windows machine can open the page as another screen. The host still has to be macOS or Linux.

Do I need Tailscale or an inbound port?

No. pairfob only dials out.

Can one device manage several computers?

Yes. A phone, tablet, or another computer can be the device. After the second host is installed: Settings → Switch computer → Add a computer.

Does it cost money?

No.
