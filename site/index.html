01How

Three steps and you are in.

Install a resident pairfob on the computer, scan once to pair. After that, Pairfob on the phone is the herd on that computer.

PrerequisitePairfob does not ship an agent. It is the phone surface for Herdr. Install Herdr 0.7 or newer; pairfob quietly starts it on launch. After installation, pairfob doctor tells you what is still missing.

The next two steps run in a terminal on the computer.

  1. 1

    On the computer with Herdr installed

    curl -fsSL https://pairfob.com/install.sh | sh

    Same command on another computer. Then on a paired device: Settings → Add another computer.

  2. 2

    Start pairing on the computer

    pairfob pair
  3. 3

    On the phone, open this URL and scan

05FAQ

A few things people get stuck on.

Accounts, a closed lid, Windows, several computers, inbound ports, and whether it costs money.

Do I need a Pairfob account?
No. There is no email login. The computer runs the install command; the device scans once.
Does locking the screen or closing the lid still work?
A locked screen is fine. A closed lid only works if the machine does not sleep. Pairfob cannot wake a sleeping computer.
Can I install pairfob on Windows?
Not yet. A Windows machine can open the page as another screen. The host still has to be macOS or Linux.
Do I need Tailscale or an inbound port?
No. pairfob only dials out.
Can one device manage several computers?
Yes. A phone, tablet, or another computer can be the device. After the second host is installed: Settings → Add another computer.
Does it cost money?
No. pairfob.com is this project's official instance. New computer setup can close; computers already set up keep working. There is no capacity promise.
