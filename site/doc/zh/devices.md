# 多台设备

电脑是一头。手机、平板、另一台电脑的浏览器都可以配对上来，连着同一群会话。每台设备各自持有凭证，不能靠「导出浏览器数据」来克隆。

## 再加一台

电脑上再执行：

```sh
pairfob pair
```

用**新设备**扫这次的码（或手输这次打印的 14 位）。不要让旧设备再扫一次——旧设备已经配过，再扫是在开一条新授权，而且会作废别人正在扫的码。

日常几部手机足够。连满时新设备会失败，需要先 `forget` 一台。

## 看谁连着

```sh
pairfob list
```

```
1  iPhone  just now
2  Android 手机  2 hours ago

Unpair one: pairfob forget 1
```

还没有设备时会提示 `Nothing paired yet. Pair one: pairfob pair`。

手机设置页也会列出已配对设备：当前设备标成「这台设备」，其他设备显示在线或离线。已解除的不会再出现在名单里。

## 解除

手机 **设置** 里点电脑卡片，**已配对设备** 里，其他设备有 **解除**。确认后那台设备立即断开，需要重新配对。同一页最下面的 **解除这台设备的配对** 只解除自己。

电脑上按 `list` 的序号也可以：

```sh
pairfob forget 1
```

也可以 `pairfob forget iPhone`。多个同名设备时必须用序号。

要踢一台已经拿不到的手机，优先用电脑：

1. 在电脑上 `pairfob list`
2. `pairfob forget N`
3. 那台设备上的本地凭证会变成废的，打开 Pairfob 需要重新配对

## 丢失或卖掉手机

1. 立刻在电脑上 `forget` 对应条目
2. 若开过通知，订阅会一并失效
3. 如果怀疑电脑本身也不干净，见 [中继看不到什么](/zh/security)

## 一部手机，多台电脑

每台电脑各自安装、各自配对。安装命令相同：

1. 在另一台电脑：`curl -fsSL https://pairfob.com/install.sh | sh`
2. 在那台电脑：`pairfob pair`
3. 在这台手机：**设置 → 切换电脑 → 添加电脑**，再扫那台电脑当前的码（桌面浏览器是输入这串码）

这台手机按电脑各存一条凭证，下次打开会连回你最近用的那台。要切换时，点会话列表顶部的电脑名；宽屏时它在左栏顶部。

电脑休眠或不在线时，名单还在。Pairfob 不会删掉这条凭证，也不会把你踢回配对页。唤醒即可，不用重新配对。锁屏可以；合盖只有系统没睡才行。

某一行的 **忘记** 只删这台浏览器里的凭证。电脑上的设备名单还在，除非你在那边 `forget`，或在设置 → 电脑卡片 → 已配对设备里 **解除**。**解除这台设备的配对** 仍然只影响当前这台电脑的配对关系。

## Herdr 通过 SSH 连接的机器

如果已配对电脑上的 Herdr 保存了 SSH 机器（`herdr machine add`），手机可以直接把它们逐台加进来，不用配对码。

1. 连上那台电脑，打开 **电脑**
2. 在 **… 能连到的机器** 下面，点某台机器的 **添加**
3. 如果那台机器没装 Pairfob，确认 **安装**。电脑会通过它自己的 SSH 连接在那台机器上安装并启动

之后这台机器出现在电脑列表里，和其他电脑一样连接。它有自己的身份和密钥；第一台电脑只转交一次性的配对链接，之后不再需要它。

需要知道的：

- 每台机器点一次，每部手机各自添加
- 电脑必须能用不需要密码、不弹任何提示的 `ssh` 连到那台机器
- 机器是 Linux 或 macOS，并使用 Herdr 的默认会话
- 电脑和机器都需要 Pairfob 1.3.0 或更高版本。电脑用 `pairfob update` 升级

在电脑终端里，`pairfob machine list` 列出同样的机器，`pairfob machine link 名字` 在这里打印那台机器的配对码。

## 另一个窗口

同一台已配对手机上再开一个 Pairfob 页，旧窗口可能提示「这台设备的连接被另一个窗口接管了」。不同**设备**可以同时连；同一设备的多个窗口会互抢。
