# 手机上怎么用

打开 Pairfob 后先看到电脑上的会话列表。点一张卡片，打开的是 Herdr 里那个真实 pane，不是副本，也不是截图流。

宽屏（大约平板横屏或桌面浏览器）会走双栏：左边列表，右边会话。手机是一屏一张。从会话左缘右滑可以回到列表。

## 列表

默认平铺全部会话，按最近操作排（新建、状态变化、点开）。设置里可以改成：

- **全部** — 一条列表
- **按工作区** — 按 Herdr 工作区分组
- **按 Agent** — 按 Agent 种类分组

分组后点标题可以展开或折叠。默认只展开第一组，其余先收着。

卡片标题是任务身份：有会话名就用会话名；没有的话，若工作区名不是当前目录名，就用工作区名；再否则用终端里像任务的标题。都没有时显示 **claude · pairfob** 这种「Agent · 目录」，纯终端则是 **终端 · pairfob**。下一行是坐标（工作区、Agent、改过的标签页、目录），不重复标题里已有的词，也不展示 `main` 这类默认标签页。不会拿内部 ID 当名称。

- **会话名**：这一块终端画面的名字；改它只影响当前会话
- **标签页名**：装着一个或多个会话的标签页；改它会影响整个标签页的识别
- **工作区名**：最外层项目容器的名字；按工作区分组时就是分组标题

| 状态 | 意思 |
| --- | --- |
| 等你 | agent 在等确认或输入，卡片更醒目 |
| 工作中 | 正在跑 |
| 空闲 | 连着但没在忙 |
| 完成 | 这一轮结束 |

已连接但列表为空时，说明 Herdr 里还没有会话，可以新建一个或在电脑上打开终端。只有页面明确显示 Herdr 没有运行时，才需要打开 Herdr；也可以在电脑上执行 `pairfobd doctor` 确认状态。

顶部「新建」在电脑当时声明了 `create_conversation` 时出现。可以选一个受支持的 Agent，也可以选 **纯终端**（不启动 Agent）：适合列表里没有的工具，或需要自己在 PTY 里操作。电脑没有提供种类时，对话框仍然能开，结果是一个纯终端会话。

## 点进会话

默认进 **控制**：电脑已经渲染好的会话，在手机上操作。不是远程桌面截图，也不是浏览器里再模拟一个终端。

标题栏：

- 左：返回列表（手机）
- 中：会话名和状态；点它可以切换到别的会话
- 工作中时会出现打断按钮，等价于对 PTY 发 Esc
- 右：`···` 更多操作

三种模式在 `···` → **模式** 里切换。某个会话里改过，只记住那一个。设置里可以改点开会话时的默认。

| 模式 | 做什么 |
| --- | --- |
| **控制** | 手机上操作这个会话：选项可点，用系统键盘，按键打回本机 PTY |
| **终端** | 真终端。vim、全屏 TUI 才需要。手机默认保持 80 列、左右滑动；**适应屏幕** 会把电脑上的终端缩到手机宽度。上下滑仍是远端 TUI 滚动 |
| **对话** | 和 Agent 发消息。任务从这里发，不在 `···` 菜单。执行过程收成一轮，完成后收起；回复按 Markdown 渲染 |

**控制**里：

- 底部输入框用**系统键盘**，听写和自动更正都可用；**组字 / 实时** 在输入框上方直接切换
- TUI 选项会抬成可点的按钮，**不会盲发 Enter**
- 点某一行可以复制整行、复制路径、引用到输入框，或进入选择文本
- 上滑或页↑是给当前 TUI 翻页，不是拉取历史缓冲
- 字号大约 9–22px，会记住
- 长行可以自动折行，也可以关掉

电脑上点过的对话框，手机上就是已经点过的；反过来也一样。没有「手机草稿」或「待同步队列」。

## 会话菜单里可能出现的操作

点 `···`。没有的项不会画出来，依据是电脑当时的 [十一项能力](/zh/capabilities)。

| 分组 | 可能有 |
| --- | --- |
| 模式 | 控制、终端（vim / TUI）、对话 |
| 输入 | 组字、实时（控制） |
| 显示 | 折行（控制）、宽度 适应屏幕 / 80 列（终端）、选择文本、文字加大/减小、复制画面文本、更早的输出 |
| 新建 | 新建标签页、分屏 |
| Worktree | 列表、新建、打开 |
| 布局 | 让这一格大一点、和对面一格对调 |
| 管理 | 改会话 / 标签页 / 工作区名字，关闭会话或整个标签页 |

路径类操作必须落在当前快照根或电脑允许的根目录。失败就关死，界面不会假装成功。**更早的输出**拉取电脑上已渲染、已停住的回看；手机不能提交路径、transcript id、读取来源或任意行数。Agent 还在画、或画面没停在底部时读不到。**对话**把一轮里的思考和工具收成可展开的执行过程，完成后自动收起；最终回复按 Markdown 渲染。点开过程才能看到参数和结果。

网页**不会**提供：任意 shell 命令、改环境变量、删除 worktree、抢电脑上的焦点、整页 `layout.apply`。创建和布局都带 `focus=false`，不会把电脑窗口抢走。

## 设置

从列表右上角进入。

- **连接**：电脑名、在线状态、这台手机的名字（例如 iPhone）。**添加另一台电脑** 再配一台，不会替换现在这台。已经有两台以上时，这里会出现 **切换电脑**，顶栏会出现 **电脑**
- **会话列表**：分组方式（**全部** / **按工作区** / **按 Agent**）
- **模式**：点开会话时默认进 **控制** / **终端** / **对话**。某个会话里再切换，只记住那一个
- **输入**：组字后发送，或边打边进终端。会话页输入框上方也可以切换，两边是同一项偏好
- **通知**：见 [通知](/zh/push)。开启后，Agent 等你处理或完成任务时会通知这台手机；电脑端没开推送时显示 **电脑端未开启**
- **已配对设备**：名称、最近使用、通知状态。当前设备标成 **这台手机**。这台手机只能解除自己的配对
- **危险操作**：**解除这台手机的配对**。之后必须重新配对

丢失的手机如果还能打开 Pairfob，最多把自己踢掉，踢不掉家里其他设备。要踢别的，用电脑上的 `pairfobd forget N`，见 [多台设备](/zh/devices)。

## 另一个窗口

同一台已配对设备上，另一个浏览器窗口打开 Pairfob 时，旧窗口可能提示「另一个窗口接管了这台手机」。只用一个打开的页面。

## 加到主屏幕

见 [开始使用](/zh/start#加到主屏幕)。iOS 建议用 Safari 添加到主屏幕后再日常使用。
