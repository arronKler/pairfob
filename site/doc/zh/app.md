# 手机上怎么用

打开 Pairfob 后先看到电脑上的会话列表。点一张卡片，打开的就是电脑上那个会话，不是副本，也不是截图。

宽屏（大约平板横屏或桌面浏览器）会走双栏：左边列表，右边会话。手机是一屏一张。从会话左缘右滑可以回到列表。

## 列表

默认平铺全部会话，按最近操作排（新建、状态变化、点开）。设置里可以改成：

- **全部** — 一条列表
- **按工作区** — 按 Herdr 工作区分组
- **按 Agent** — 按 Agent 种类分组

分组后点标题可以展开或折叠。默认只展开第一组，其余先收着。有 **置顶** 时，置顶和它下面那一组默认展开。

卡片大字只放一个身份：有会话名就用会话名；没有的话，若工作区名不是当前目录名，就用工作区名；再否则用终端里像任务的标题（会去掉 `Thinking` / `Waiting for response` 和末尾的 ` - grok`）。都没有时，有 Agent 就写 **claude**，纯终端写 **终端**。下一行永远是坐标，顺序是 **claude · pairfob**（Agent · 目录 · 非默认标签页），不重复大字里已经有的词，也不展示 `main`。不会拿内部 ID 当名称。

- **会话名**：这一块终端画面的名字；改它只影响当前会话
- **标签页名**：装着一个或多个会话的标签页；改它会影响整个标签页的识别
- **工作区名**：最外层项目容器的名字；按工作区分组时就是分组标题

| 状态 | 意思 |
| --- | --- |
| 等你 | agent 在等确认或输入，卡片更醒目 |
| 工作中 | 正在跑 |
| 空闲 | 连着但没在忙 |
| 完成 | 这一轮结束 |

已连接但列表为空时，说明 Herdr 里还没有会话，可以新建一个或在电脑上打开终端。只有页面明确显示 Herdr 没有运行时，才需要打开 Herdr；也可以在电脑上执行 `pairfob doctor` 确认状态。

顶部「新建」在电脑支持时出现。列表长按或会话 `···` 里的 **新建标签页**，以及会话 `···` 里的 **分屏**，用同一份 Agent 种类列表：可以选一个 Agent，也可以选 **纯终端**。电脑没有列出 Agent 种类时，对话框仍然能开，结果是一个纯终端会话。正在新建的 Worktree 会出现在列表上方，完成前可以取消。

点卡片进去。长按（电脑上右键）可以 **置顶**、在同一工作区再开一页、改名或关闭这份会话。置顶的会话出现在列表最上面的 **置顶** 分组，不再留在原来的工作区或 Agent 组里；再长按 **取消置顶**。标签页已经有可见名字、或正在分屏时，才会出现改标签页名；关整个标签页只在分屏时出现。按工作区时，长按分组标题可以 **在这个工作区新建标签页**、改工作区名，或 **关闭这个工作区**；其他分组方式下，工作区改名和关闭在卡片长按菜单最底下。电脑支持新建标签页时，新建入口才会出现。分屏仍在点进会话后的 `···` 里。

顶部的 **画板**（卡片长按或会话 `···` 里的 **看标签页布局**）打开当前标签页在电脑上的真实分栏。可以捏合或滚轮缩小，一眼看到整个标签页。上面一排是工作区，下面一排是标签页，也可以在这里新建标签页。点一格就打开那个会话。这里切换工作区或标签页不会抢走电脑上的焦点。

## 点进会话

默认用 **自动**：P2P 直连、浏览器支持 WebGL2 且未开启省流时进入真终端，否则进入控制。电脑上已经打开的会话仍在电脑上运行，不是远程桌面，也不是浏览器里再开一个终端。

标题栏：

- 左：返回列表（手机）
- 中：会话名和状态；点它可以切换到别的会话
- 工作中时会出现打断按钮，相当于按 Esc
- 右：文件夹 **查看文件与更改**，然后 `···` **会话操作**（怎么看、怎么输入，以及改这一格的名字、关掉这一格）

四个选项在 `···` → **模式** 里切换。某个会话里改过，只记住那一个。设置里可以改点开会话时的默认。

| 模式 | 做什么 |
| --- | --- |
| **自动** | 打开会话时选择：P2P 直连、支持 WebGL2 且未开启省流时用终端，否则用控制 |
| **控制** | 查看终端画面，用系统键盘和按键垫操作这个会话 |
| **终端** | 真终端。vim、全屏 TUI 才需要。手机默认保持 80 列、左右滑动；**适应屏幕** 会把电脑上的终端缩到手机宽度。上下滑仍是远端滚动 |
| **对话** | 和 Agent 发消息。任务从这里发，不在 `···` 菜单。执行过程收成一轮，完成后收起 |

**控制**里：

- 底部输入框用**系统键盘**，听写和自动更正都可用；**组字 / 实时** 在输入框上方直接切换
- 终端里的确认选项保留原样；按提示用按键垫的 ↑/↓ 选择，再按 Enter 确认。需要输入字母或文字时，按终端提示输入
- 右侧是 **Enter**：没字就是终端回车，有字则先打字再确认
- 点某一行可以复制整行、复制路径、引用到输入框，或进入选择文本
- 上滑或页↑是给当前画面翻页，不是拉取历史
- 字号会记住
- 长行可以自动折行，也可以关掉
- 按键垫默认是 Esc 和方向键。**更多按键** 会加上 Tab、Ctrl+C，以及 **命令** 格（`/clear`、`/goal` 这类会写进终端，Pairfob 不解释）

**对话**模式显示「等你」时，点 **去确认** 会切到 **控制**，查看终端里的确认提示。确认前先读清操作和当前选项；需要时也可以从 `···` → **模式** 切到 **终端**。

电脑和手机操作的是同一个终端中的确认框，一边完成确认后，另一边会看到更新后的状态。如果手机看不到提示，先在电脑上处理，并反馈手机所在模式、Agent / 扩展版本和脱敏录屏。

## 查看文件与更改

会话顶栏的文件夹不是 Worktree 菜单，打开的是这一格的工作区：

- **文件** — 目录列表和文本预览
- **更改** — 未提交的 Git 状态；点文件看 diff
- 点 diff 的一行写批注，再 **发给 Agent**
- 分支列表只读；切换工作走 Worktree

电脑端 daemon 还不支持时，页面会说明。

## 会话操作里可能出现的操作

点会话标题栏右侧 `···`。电脑当时做不到的项不会出现。改标签页名、改工作区名、关闭整个标签页、关闭这个工作区在列表长按菜单里，不在这里。

| 分组 | 可能有 |
| --- | --- |
| 模式 | 自动、控制、终端（vim / TUI）、对话 |
| 输入 | 组字、实时（控制） |
| 显示 | 折行（控制）、宽度 适应屏幕 / 80 列（终端）、选择文本、文字加大/减小、复制画面文本。**对话**里不出现这一组 |
| 新建 | 新建标签页、分屏 |
| Worktree | 列表、新建、打开 |
| 布局 | 让这一格大一点、和对面一格对调 |
| （无分组） | 改会话名、关闭这个会话 |

**对话**把一轮里的思考和工具收成可展开的过程，完成后自动收起。展开可看参数和结果。完成的回答可以 **复制回答**；线程很长时 **加载更早内容**。

网页不会任意执行命令、删 worktree，也不会把电脑窗口抢到前台。

## 设置

从列表右上角进入。

- **连接**：电脑名、在线状态、这台手机的名字（例如 iPhone），以及 **网络连接方式**：**自动** / **P2P** / **Relay**。自动优先直连，不通时用中继；P2P 立即尝试直连；Relay 只用中继。同一张卡片上显示当前路径和往返时延。这个选择会留在这台浏览器上。**添加另一台电脑** 再配一台，不会替换现在这台。已经有两台以上时，这里会出现 **切换电脑**，顶栏会出现 **电脑**
- **订阅余量**：这台电脑已登录账号的额度（Codex、Claude Code、GitHub Copilot、Cursor、Grok、Antigravity）。概览是环；**用量详情** 看各窗口。详情页可以 **刷新余量**。没有数据或已过期时不会显示成零
- **语言**：**跟随浏览器**，或固定 **中文** / **English**。只作用于这台设备上的 Pairfob 页面，和文档右上角的语言不是同一项
- **会话列表**：分组方式（**全部** / **按工作区** / **按 Agent**）
- **模式**：点开会话时默认用 **自动**，也可以固定为 **控制** / **终端** / **对话**。某个会话里再切换，只记住那一个
- **输入**：组字后发送，或边打边进终端。输入框旁的 **Enter** 在没有草稿时也会向终端发送回车。会话页输入框上方也可以切换，两边是同一项偏好
- **通知**：见 [通知](/zh/push)。开启后，Agent 等你处理或完成任务时会通知这台手机；电脑端没开推送时显示 **电脑端未开启**
- **已配对设备**：名称、在线或离线、最近使用、通知。当前设备标成 **这台手机**。其他设备可以点 **解除**；已解除的不再列出
- **更新电脑端**：列表上会提醒，设置页底部可以 **检查更新** / **更新电脑端**（用户服务安装才支持从手机更新）。确认后会短暂断开再连上。不会自动安装。命令行见 [命令行](/zh/cli)
- **危险操作**：**解除这台手机的配对**。之后必须重新配对

丢失的手机如果还能打开 Pairfob，也可以从设置里解除其他设备。立刻在电脑上 `pairfob forget` 那台手机，见 [多台设备](/zh/devices)。

## 另一个窗口

同一台已配对设备上，另一个浏览器窗口打开 Pairfob 时，旧窗口可能提示「另一个窗口接管了这台手机」。只用一个打开的页面。
