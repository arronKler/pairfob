# 常见问题

## 要不要注册 Pairfob 账号？

不要。没有邮箱登录。电脑跑安装脚本时完成登记，设备用配对拿到凭证。凭证分别在电脑的状态目录和这台浏览器里。

## Pairfob 能单独跑 agent 吗？

不能。它是 [Herdr](https://herdr.dev) 的手机端。电脑上要装 Herdr 0.7 或更高；默认单会话下，`pairfobd` 会在启动时自动拉起持久 Herdr server。自动启动失败时列表会显示 Herdr 离线，手动运行 `herdr` 后会自动恢复。

## 这是远程桌面吗？

不是。它不投屏、不搬鼠标、不打开你的 IDE 窗口。它只接 Herdr 里已经渲染好的 pane，把按键打回本机 PTY。见 [同一块屏幕](/zh/model)。

## 手机上的能力和电脑上一样吗？

以**正在跑的** Herdr 为准。CLI 当时做得到的，手机上才会出现对应控件；做不到的不画，也不会假装成功。网页还故意少了一批能力（任意命令、删 worktree、抢焦点）。见 [能力从哪来](/zh/capabilities)。

## 出门再打开，是同一个会话还是拷贝？

同一个。没有「同步到手机」。坐回来也不用同步回桌面。见 [出门和回来](/zh/continue)。

## 锁屏或合盖之后还能用吗？

锁屏可以。Pairfob 不需要桌面保持解锁。登录会话、`pairfobd`、Herdr、以及到 `pairfob.com` 的出站连接，都会在锁屏后面继续跑。

合盖只有系统**没有真的睡眠**才行。笔记本默认合盖就是睡眠：进程冻住、网络断开，手机上会看到 **电脑现在不在线**。Pairfob 唤不醒已经睡着的电脑，也不能远程解锁。

出门还想接着用：

- 锁屏。盖子保持打开，或确认系统合盖后不会睡再合
- macOS：`Control-Command-Q` 锁屏。电池设置里，至少在接通电源时不要在显示器关闭后自动睡眠。合盖 + 电源 + 外接显示器是 clamshell，机器会保持醒着
- Linux：桌面电源设置里把合盖设成「什么都不做」或「锁屏」
- macOS 上临时保活用 `caffeinate` 这类系统命令，不是 Pairfob 的功能。不要合盖塞进包里还强制不睡

电脑醒来后，`pairfobd` 会自己重连，不用重新配对。睡着的电脑仍留在手机名单上，这和解除配对不是一回事。见 [出门和回来](/zh/continue)。

## 断网了要重新配对吗？

不要。凭证还在浏览器里。网络恢复后会重连。只有清站点数据、换浏览器、或电脑上 `forget` 了，才需要重新配对。

## 支持 Windows 吗？

还不能在 Windows 上装 `pairfobd`。另一台 Windows 电脑可以用浏览器打开 <a href="/pair">pairfob.com/pair</a> 当「第二块屏幕」，宿主仍然必须是 macOS 或 Linux。

## 要不要 Tailscale / 端口转发？

不要。`pairfobd` 只出站。家里路由器不用为 Pairfob 开端口。

## 中继能看到我的代码吗？

看不到 pane 文本、按键和 RPC 内容。它能看到路由标识、密文长度和限流所需的 IP。见 [中继看不到什么](/zh/security)。

## 二维码被别人拍到了怎么办？

电脑还没按 Enter 之前，对方配不上。已经按了 Enter、对方已经出现在 `pairfobd list` 里，就立刻 `forget` 那一台。码本身用过即废。

## 手机丢了怎么办？

电脑上 `pairfobd list`，对对应序号 `pairfobd forget N`。那台手机上的凭证作废。丢失的手机最多只能解除自己，解除不了你的其他设备。

## 清掉 Safari 数据之后？

等于这台设备没配对过。重新 `pairfobd pair`。电脑上的其他设备不受影响。

## 一部手机能连两台电脑吗？

可以。另一台电脑先跑同一条安装命令，再 `pairfobd pair`，然后在手机上 **设置 → 添加另一台电脑**。手机两边的凭证都留着，下次打开连回最近用的那台。主页 **电脑** 可以切换。电脑不在线时名单还在，这和解除配对不是一回事。见 [多台设备](/zh/devices)。

## 手输为什么要 14 位？

8 位是秘密，6 位只用来找到你的电脑。只输 8 位页面不会发出去。扫码不走这 6 位。见 [配对](/zh/pair)。

## 安装命令能在第二台电脑再用吗？

能。每台电脑各自跑 `curl -fsSL https://pairfob.com/install.sh | sh`。然后在手机上：**设置 → 添加另一台电脑**。已经登记的机器靠 `relay.json` 重连。更新用 `pairfobd update`。

## 安装时登记失败？

先看网络和 `pairfobd doctor`。不要设 `PAIRFOB_JOIN_TOKEN`。如果这个网络今天登记的电脑太多，明天再试。

## 列表是空的？

按顺序查：电脑 `pairfobd doctor` 里 Herdr 是否 `on`。空标题 **还没有读到会话** 表示 Herdr 没开；**还没有会话** 表示已经连上但还没有 pane。Pairfob 是否已经配对成功（不是停在扫码页）。

## 为什么没有「新建 / 分屏 / Worktree」？

电脑当时的 Herdr 没声明那一项能力。升级并**重启正在跑的 Herdr 服务**后再看，不是只装一个新的 CLI 二进制。`agent_kinds` 为空时，顶部 **新建** 仍可用来开纯终端。没有 **铺满全屏** 时，会话菜单会写明当前 Herdr 还不支持把分屏铺满。

## 点了按钮但不确定电脑做了没有？

不要连点。若看到「电脑可能已经执行了操作」，先看画面或回列表刷新。Pairfob 不会自动重试 mutation。

## 通知为什么开不了？

默认关。先在电脑环境里设 `PAIRFOB_PUSH=1` 和合法的 `PAIRFOB_VAPID_SUBJECT`，写进用户服务，再 `pairfobd service restart`。然后到手机设置里订阅。见 [通知](/zh/push)。

## 可以给同事也扫这个码吗？

不要把当前码当团队邀请。配对的是**你的电脑**上的 Herdr。每个要连的人 / 设备都应在你知情下单独 `pair`，并且你在电脑上按 Enter。不该连的用 `forget`。

## 一份 Pairfob 能接两台电脑吗？

可以。同一个浏览器配置能为多台电脑分别保存一条配对凭证。第二台电脑先跑 `curl -fsSL https://pairfob.com/install.sh | sh`，再 `pairfobd pair`，然后在 **设置 → 添加另一台电脑** 扫码。每台电脑仍需单独配对，而且一台 `pairfobd` 只连一个 origin。

## 收费吗？

入口和网页按现在的产品是可以直接用的。本文不承诺容量 SLA；「能撑多少并发」是设计目标，不是对你个人连接的保证。
