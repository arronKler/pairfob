# 同一块屏幕

Pairfob 不是在浏览器里再开一个终端，也不是远程桌面。电脑上 Herdr 里跑着的会话，手机打开就是那个。两边看见同一块屏幕，谁操作都算数。

Agent 仍在你电脑上跑。`pairfob.com` 只帮忙传消息，不跑 Agent，也看不到屏幕内容。

## 想保住的循环

1. 电脑上 Agent 在跑
2. 它停下来等你（也可以推一条通知）
3. 打开的就是那个会话，不是另开一条
4. 确认框可以点，不会替你乱按回车
5. 用手机自带键盘接着说
6. 坐回电脑前，接着就是这一步

电脑当时做得到的，手机上才会出现；做不到的不画出来。

## 因此

- 出门打开，就是电脑上那个会话
- 坐回来不用同步、不用关远程窗口
- 没有「手机专用精简命令集」

这不是镜像一份副本。手机上的窗口和电脑上的窗口是同一个。

## 和常见方案比

| | Pairfob | 网页终端 | 远程桌面 | 云端 agent |
| --- | --- | --- | --- | --- |
| 会话在哪 | 你的电脑 | 往往另开一条 | 整台桌面 | 别人的机器 |
| 回来要不要合并 | 不要 | 常常要 | 要面对两套操作 | 两套上下文 |
| 家里开端口 | 不要 | 视方案 | 常见 | 不要 |
