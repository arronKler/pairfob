# 配对

配对是**授权**，不是账号登录。Pairfob 没有用户名、邮箱或云端账号。未配对时还不能操作。电脑上确认之后，这台设备才拿到凭证。

凭证留在**这台设备的这个浏览器**里。换浏览器、清站点数据、卸载 PWA 或开无痕，等于要重新配对。

## 电脑上怎么开

在已经在跑 `pairfob` 的电脑上：

```sh
pairfob pair
```

它会：

1. 优先画出二维码
2. 同时打印一串给手输用的码
3. 等另一台设备证明配对码
4. 在终端里问你一次 Enter

没有网页确认页。不要在另一台机器的浏览器里找「同意配对」按钮——同意只发生在这台电脑的终端。

::: warning 同一时间只有一个配对
另一台电脑如果也执行了 `pairfob pair`，旧码会失效。手机上可能看到「另一台电脑开启了配对」或「配对码过期或已经用过」。用**当前**这台电脑刚打印的码。
:::

## 另一台设备怎么连

打开 <a href="/pair">pairfob.com/pair</a>。已配对过的设备会直接进会话列表，不会再停在扫码页。

### 扫码（优先）

对准电脑上的二维码即可。摄像头权限只用于这一次扫描。

### 手输

手输必须带 **8 位配对码 + 6 位定位码**。没有只输 8 位就能连上的路径。

- 页面上只有一个输入框；一次粘贴 14 个字符即可（允许空格和横线；`O` 当 `0`，`I` / `L` 当 `1`）
- 只交 8 位时，页面提示要完整输入，**不会发出去**

这两段职责不同：

| 段 | 长度 | 作用 |
| --- | ---: | --- |
| 配对码 | 8 | 秘密。用来证明你看见了电脑屏幕 |
| 定位码 | 6 | 只用来找到那台电脑，不是同一等级的秘密 |

## 电脑上按 Enter

**只在电脑终端按 Enter 才真正放行。** 手机扫完之后仍要等这一下。两边都不展示安全词。这是为了防止：别人拍到你屏幕上的码，在你不知情时配上。

不是你的设备就在电脑上拒绝（Ctrl-C 或等它过期），重新 `pairfob pair`。

## 配对码过期或输错

电脑上的码**用过即废**，过一段时间也会过期。不要用聊天记录或上周截图里的码。

| 你看到的 | 含义 | 做什么 |
| --- | --- | --- |
| 配对码过期或已经用过 | 码已经换了，或失效 | 看电脑**当前**打印的码 |
| 请完整输入电脑上显示的配对码 / 还没输完整：需要 14 位 | 手输缺了定位码 | 把 8+6 一起贴进去 |
| 配对码不正确 | 对不上 | 用新码，不要改旧码碰运气 |
| 配对连接超时 | 网络或电脑端已离开等待 | 重新扫或重新输当前码 |
| 尝试太频繁 | 这一侧被限流 | 等一会儿再试 |
| 另一台电脑开启了配对 | 被新的 `pair` 挤掉 | 在你要连的那台电脑上重新开 |

## 配对完成之后

- 下次打开 <a href="/pair">pairfob.com/pair</a> 会连回这台浏览器最近用的那台电脑
- 同一部手机再连另一台电脑：那台电脑先用同一条命令装 pairfob，再 `pairfob pair`，然后设置 → **添加另一台电脑**，见 [多台设备](/zh/devices)
- 再加设备：在电脑上再执行一次 `pairfob pair`，用**新设备**扫新码，见 [多台设备](/zh/devices)
- 手机设置里只能解除自己；解除别人用电脑上的 `pairfob forget N`

## 不要做的事

- 不要把配对码贴到别人的网页或群里
- 不要把已配对浏览器的数据拷到另一台手机当「克隆」
- 不要在电脑没确认之前以为已经配上
- 不要同时在两台电脑上开配对还用旧码
