# 出门和回来

这是 Pairfob 想保住的循环：电脑上开始，路上接着，坐回来还是刚才那一步。

Agent 一直在电脑上跑。Pairfob 只是把那块屏幕接到另一台已配对设备。没有「同步到手机」或「同步回桌面」这种步骤，也没有主控 / 从控切换。

## 在电脑前

照常用 Herdr。不必先打开 Pairfob，也不必把某个会话「标记为可远程」。只要 `pairfobd` 在跑（安装后一般随登录启动），配对过的设备随时可以接上来。

电脑上的 Herdr 窗口本来就是主控。手机只是同一块屏幕的另一块玻璃。

## 突然要出门

1. 电脑上的 Herdr 和 `pairfobd` 继续跑
2. 可以锁屏——Pairfob 不需要桌面保持解锁
3. 盖子保持打开，或确认系统合盖后不会睡再合
4. 打开 Pairfob（浏览器或加到主屏幕的 PWA）
5. 点进刚才那个会话

确认对话框、打字、开 worktree，都打回本机。如果开了 [通知](/zh/push)，Agent 等你或完成时，点推送会进入那台电脑的那个会话，而不只是打开首页。

问题不在锁屏，在睡眠。合盖塞进包里不是 Pairfob 的场景：手机接不上，Pairfob 也唤不醒这台电脑。醒来后会自己重连，不用重新配对。锁屏和合盖的差别见 [常见问题](/zh/faq)。

## 坐回工位

手机上刚点过的对话框、刚改过的布局、刚打的字，还在电脑上。你不需要：

- 点「同步到桌面」
- 断开远程会话
- 在电脑上重新打开同一个 agent 窗口当「主控」
- 把手机上的草稿拷回来

两边本来就是同一个 pane。坐下来接着看 Herdr 即可。

## 路上断了一下

WebSocket 会重连。凭证还在这台浏览器里，不需要重新扫码。重连成功后列表和画面会跟上电脑当前状态，而不是重放你离线时积压的按键。

如果电脑端 `pairfobd` 重启了，已配对设备仍然有效（凭证在电脑的状态目录里），但进行中的配对槽会作废。

## 多台设备同时开着

平板或另一台电脑的浏览器同样可以配对。看到的、能操作的，和手机上一样，也和电脑上的 CLI 一样。多台同时连着时，它们看到的仍是同一群会话。

同一台手机的两个窗口会互抢，见 [手机上怎么用](/zh/app#另一个窗口)。不同设备之间不会「谁是主控」——都是同一块屏幕。

## 和「远程开发」的差别

| 远程桌面 / SSH 终端 | Pairfob |
| --- | --- |
| 另开一条会话或整桌面 | 接上已经在跑的 Herdr pane |
| 回来时要处理两份状态 | 回来时只有一份状态 |
| 往往要开端口或组网 | 电脑只出站 |
| 键盘是远程协议里的键 | 系统键盘 → 本机 PTY |
