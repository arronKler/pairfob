# Android 测试版

Android beta 将 Pairfob 打包为手机和平板应用，通过 `pairfob.com` 连接电脑上运行的
Agent。当前通过 APK 侧载安装，尚未上架应用商店。使用时请保持电脑运行并联网。

## 安装和配对

1. 使用 Android 7.0 或更新版本，并更新 Android System WebView 和浏览器。
2. 在电脑上[安装 Pairfob](/zh/install)，启动服务。
3. [下载最新 beta](https://dl.pairfob.com/android/beta/latest.apk)。
   当前版本和更新说明见[发布清单](https://dl.pairfob.com/android/beta/latest.json)，
   旧版本在 [GitHub Releases](https://github.com/arronKler/pairfob/releases)。
4. 打开下载的 APK。如系统提示，请为下载所用的浏览器开启「允许安装未知应用」。
   安装后可以关闭这项权限。
5. 打开 Pairfob，在电脑运行 `pairfob pair`，扫码或输入配对码，核对确认词后在电脑确认。

Android 应用自带一份 web 资源。pairfob.com 上的网页更新不会自动进入已安装的应用，
需要等下一个 beta 安装包。

请只使用官方下载站或上面链接的 GitHub 发布页。应用包名为 `com.pairfob.app`，
beta 签名证书 SHA-256 为：

```text
1df205898f9e85ab178d280d3a7a5af5a683e5c686ac7e0df3c37057a64349dc
```

## 更新并保留配对

在**设置**中找到 Android 应用版本，点击**检查更新**。有新版时，**下载并安装**会
打开系统浏览器；下载后接受 Android 的更新安装提示。重新打开应用，确认版本变化、
电脑仍已配对。不要先卸载或清除应用数据，这会删除本地配对信息。

应用在启动和返回前台时也会自动检查，成功检查后六小时内不重复检查；手动检查不受
这个间隔限制。应用不会自动安装。Android 校验安装包签名；应用本身不校验下载文件
的 SHA-256，发布清单中的哈希可用于手动核验。

安装失败时，请记录系统报错、已安装版本和下载版本。修复会以更高版本号发布，请勿降级。

## 建议测试内容

- 配对、退出重进，在 Wi-Fi 和移动数据之间切换。
- 打开会话、读取终端，在专门的测试会话里发送无害命令。
- 将已完成的会话标记已读，重连后确认已读状态保留。
- 打开文件与更改，在测试会话发送一个不含敏感内容的小附件，并在电脑确认结果。
- 横竖屏切换；有硬件键盘时，尝试键盘输入。
- 在设置里开启通知，把应用切到后台，确认在接下来十五分钟左右结束的会话能收到通知。
  手机休眠时可能更久，原因见「当前限制」。
- 从旧 beta 覆盖安装更新，确认配对和偏好设置保留。

## 当前限制

- 没有厂商推送通道（FCM 或各家 OEM 通道）。通知来自大约每十五分钟一次的后台定时检查。
  检查会唤醒应用，离屏加载它的网页，连上你的电脑，并在会话结束或需要你处理时发出通知。
  因此通知最多会晚这么久，而手机休眠时 Android 会推迟检查，最晚可能拖到几小时。实测：
  应用留在后台、网页被隐藏后，5 分钟内就不再响应，所以检查用的是它自己的网页，而不是
  应用已在运行的那个。要在事件发生的那一刻就送达，需要推送通道，本 beta 不支持。
- 中国大陆网络和各厂商系统尚未广泛验证。Android 7.0 是最低可安装版本，不代表全部
  Android 版本都已测试。
- 没有自动崩溃上报，需要测试者主动反馈可复现的问题。
- 缺少安全消息接口的旧 WebView 无法使用应用内更新。请更新 Android System WebView，
  或从官方发布清单下载 APK，覆盖安装到现有应用上。

## 反馈问题

[提交 beta 反馈](https://github.com/arronKler/pairfob/issues/new?template=android-beta.yml)，
附上应用和 daemon 版本、手机型号、Android/WebView 版本、网络类型、复现步骤、预期
和实际结果，并说明是全新安装还是覆盖更新。Issue 公开可见，请打码截图，不要上传
配对码、二维码链接、密钥、私人命令或对话内容。

服务元数据与本地数据的说明见[隐私](/zh/privacy)；手机丢失时，请通过
[设备管理](/zh/devices)撤销访问权限。
