# 实时输入性能

本页覆盖引导终端底部的“实时”输入，不是完整 xterm 终端。输入 mutation
仍然一次只发送一次；连接中断后的未知结果只刷新确认，不自动重放。

实时输入分成两个反馈层：

- 本机反馈：输入事件同步更新“本机待回显”预览，首批在下一帧发送。
- 电脑画面：`PaneRead` 在同一个有序会话中直接排在 `SendText` 后面，
  不再先等待 mutation ACK 再发读取请求。

运行虚拟 RTT 基准：

```sh
bun run perf:live-input
```

基准报告本地状态反馈、首个远端画面估算、批次数和完成时间。它验证队列
与网络往返模型，不等同于真实手机、WSS、daemon、Herdr 和实体键盘测试；
发布门槛应使用同一台真机重复采集的 p50/p95。
